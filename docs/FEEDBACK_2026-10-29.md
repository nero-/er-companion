# Player feedback round — 2026-10-29

Source: `Elden Ring Companion Comments 102926` (user-supplied review). This file records what
each comment asked for, what changed, and how it was verified. Every claim below was exercised
against a running build; nothing here is aspirational.

## Display and legibility

| Comment | Change | Verification |
| --- | --- | --- |
| "Displays in 1080p … should adapt to the user's screen" | Interface scale resolves from the logical viewport: 1.0 at 1080p, 1.1 at 1440p, 1.25 at 2160p. OS-scaled 4K (1920×1080 CSS px) intentionally stays at 1.0 so desktop scaling and app scaling do not compound. Recomputes on resize and DPR change. | Measured `--ui-scale` at 1920×1080 (1.0), 2560×1440 (1.1), 3840×2160 (1.25), and 4K-at-200% (1.0). No horizontal overflow at any of those or at 390px. |
| "Fonts are too small … especially in the side menus" | Type floor applied across the CSS: nav items 15px, nav labels 11.5px, badges/tables 12px, with a scale multiplier. All sub-11.5px declarations were raised or re-expressed through the scale. | Computed nav font 15px at 1.0, 18.75px at 4K; smallest sidebar text 11.5px at 1.0. |
| "Performance is very slow on linux app image" | Two causes. The Rust shell forced the WebKitGTK software renderer on every Linux launch; it now uses hardware rendering and falls back only for remote X11 or software GL. CSS removed all `backdrop-filter`, the full-viewport scanline overlay, and the filtered fixed backdrop; long lists use `content-visibility`. | 20 scroll steps over 3,921px of route produced 0 long tasks; computed `backdrop-filter` is `none` on sidebar and topbar. |

## Performance and delivery

- Pages are lazily imported; the 6.9 MiB build reference pack is a separate chunk fetched on
  demand; boss names and strategy counts come from a 1.7 KiB index so the shell and search never
  load it.
- A page-level error boundary keeps navigation, search and progress usable if one page fails.
- Production build: 12 routes render, no error boundary, service worker active with 62 precached
  entries, and a full offline reload renders the dashboard.
