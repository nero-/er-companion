## Anomalies and notes

1. Route — base missable denominator: the contract states 170 but the widest artifact count is 169 (165 MISSABLE badges + 1 missable-trophy marker-only + 3 text-only warnings). The shortfall is 1 by the widest definition and 2 under the integration's badge-or-text rule. Do not hardcode 170 when asserting coverage.
2. Route — base has 3 section(s) with an empty level range: Starting Out, Endings, New Game Plus Preparation. This is source data, not a scrape failure.
3. Route links include 51 relative hrefs (49 base + 2 DLC): site-root image paths, in-page anchors, and two `/sheets/...` links. They preserve the source exactly, but must be resolved against `https://eldenring.redmaw.dev` before rendering in the standalone app; otherwise deep links and image links break. The two absolute-URL check failures are this single normalization issue.
4. Maliketh split: `w46-96` is the warning immediately after the `w46-95` Maliketh kill; `w46-97..99` are the three post-Maliketh steps. The split is arithmetically compatible with the contract.
5. Item info coverage is 168/2,100 (8.0%); 1,932 records legitimately have no source `span.info`. Integration must not treat empty info as a merge failure.
6. One cross-group name collision survives: `Beast Claw` is both a Weapon (`rw-weapons-e29-1`) and a Spell (`rw-spells-s14-7`). The documented name+group+category key keeps both; name-only matching would collapse them.
7. Merchant extraction has 627 purchasable rows plus 97 nested heading rows (e.g. 'After moving to the Scenic Isle…:'), totaling 724 source checkboxes. Only the 627 item rows should be rendered as stock.
8. The raw achievements sheet has 72 checkboxes: 42 achievements (9 misc, 24 bosses, 6 shardbearers, 3 endings) plus 30 legendary requirement items (9 weapons, 6 ashes, 7 spells, 8 talismans). The four requirement-group rows are not achievements.
9. Boss rows are 207 encounters but only 157 unique normalized names. The 50 extra rows are repeat encounters (Tree Sentinel, Night's Cavalry, Deathbird, etc.) with distinct IDs and sections; name-only merging would lose them.
10. Boss `achievement` values are display names, not achievement slugs; integration must map them to the 42 achievement IDs.
11. Two Dung Eater questline steps carry source-numbered badges `#2 MISSABLE` and `#4 MISSABLE` rather than plain `MISSABLE`. Integration warning checks should use a case-insensitive substring match, not equality.

- Shadow of the Erdtree: 20 sections / 1,126 steps, from `west-gravesite` through `enir-ilim`.

Canonical arithmetic: 3,303 pre-DLC steps + 1,126 DLC steps + 92 endgame steps (3 synthetic aftermath + 89 base endgame) = **4,521 steps**. Section arithmetic: 46 base pre-DLC + 20 DLC + 1 synthetic aftermath + 3 base endgame = **70 sections**.
